## ✨ Tentang KolabSpace

**KolabSpace** adalah platform kolaborasi modern yang dirancang untuk meningkatkan produktivitas tim dengan antarmuka yang elegan dan intuitif. Dibangun dengan teknologi web terkini, KolabSpace menyediakan solusi lengkap untuk manajemen proyek, komunikasi tim, dan kolaborasi real-time.

### 🌟 Mengapa KolabSpace?

- **🎨 UI/UX Modern** - Desain dark theme dengan gradient biru-ungu yang eye-catching
- **⚡ Super Fast** - Pure vanilla JavaScript tanpa framework, loading super cepat
- **📱 Fully Responsive** - Sempurna di semua device, dari mobile hingga desktop
- **🎯 User-Centric** - Dirancang dengan fokus pada pengalaman pengguna
- **🔒 Secure** - Sistem autentikasi yang aman dengan role-based access
- **♿ Accessible** - Mengikuti standar aksesibilitas web modern

## 🚀 Quick Start

### Prerequisites
- Web browser modern (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, dll)
- (Optional) Local server seperti Live Server, XAMPP, atau Python SimpleHTTPServer

### Installation

1. **Clone repository**
   ```bash
   git clone https://github.com/yourusername/KolabSpace.git
   cd KolabSpace
   ```

2. **Open dengan browser**
   
   **Opsi 1: Direct Open**
   ```bash
   # Buka index.html langsung di browser
   open index.html
   # atau
   start index.html
   ```

   **Opsi 2: Local Server (Recommended)**
   ```bash
   # Menggunakan Python
   python -m http.server 8000
   
   # Menggunakan PHP
   php -S localhost:8000
   
   # Menggunakan Node.js http-server
   npx http-server -p 8000
   ```

3. **Access aplikasi**
   - Landing Page: `http://localhost:8000/index.html`
   - Login: `http://localhost:8000/login.html`
   - User Dashboard: `http://localhost:8000/user.html`
   - Admin Dashboard: `http://localhost:8000/admin.html`

### Default Login Credentials

```javascript
// Admin Account
Username: admin
Password: admin123

// User Account  
Username: user
Password: user123
```

## 🎨 Customization

### Color Scheme
Edit variabel di `src/css/style.css`:

```css
/* Primary Colors */
--primary-dark: #0a0f2e;
--primary-medium: #11193a;
--primary-light: #1a2349;

/* Accent Colors */
--accent-blue: #3b82f6;
--accent-purple: #8b5cf6;
--accent-blue-light: #60a5fa;
--accent-purple-light: #a78bfa;

/* Status Colors */
--success: #4ade80;
--warning: #fbbf24;
--danger: #f87171;
```

### Typography
Ganti Google Font di bagian atas CSS files:

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap');

body {
    font-family: 'Inter', sans-serif;
}
```

### Layout
Adjust sidebar width:

```css
.sidebar {
    width: 280px; /* Default */
}

.sidebar-collapsed {
    width: 80px; /* Collapsed */
}
```

## 🔧 CSS Architecture

KolabSpace menggunakan arsitektur CSS yang modular dan efisien:

### 📦 File Structure

```
style.css (Global)
├── Reset & Base Styles
├── Common Components
│   ├── Logo
│   ├── Sidebar
│   ├── Navigation
│   ├── Top Bar
│   ├── Profile Dropdown
│   ├── Modals
│   ├── Cards
│   └── Forms
└── Responsive Rules

admin.css (Admin-specific)
├── Navigation Sections
├── Tables
├── Admin Badges
└── Admin Actions

user.css (User-specific)
├── Progress Bars
├── Discussion Lists
├── Task Items
└── Timeline

login.css (Login-specific)
├── Login Container
├── Feature Highlights
└── Footer
```

### 🔗 Import Order

**Critical**: Import dalam urutan yang benar!

```html
<!-- ✅ Correct -->
<link rel="stylesheet" href="src/css/style.css">
<link rel="stylesheet" href="src/css/admin.css">

<!-- ❌ Wrong -->
<link rel="stylesheet" href="src/css/admin.css">
<link rel="stylesheet" href="src/css/style.css">
```

## 📱 Responsive Design

### Breakpoints

```css
/* Mobile First Approach */

/* Extra Small Devices (≤480px) */
@media (max-width: 480px) { }

/* Small Devices (≤600px) */
@media (max-height: 600px) { }

/* Medium Devices (≤768px) */
@media (max-width: 768px) { }

/* Large Devices (≤1024px) */
@media (max-width: 1024px) { }

/* Extra Large (≥1025px) */
@media (min-width: 1025px) { }
```

### Mobile Features

- ✅ **Touch-Optimized**: Larger tap targets (45px minimum)
- ✅ **Gesture Support**: Swipe untuk sidebar
- ✅ **Optimized Layout**: Stack pada screen kecil
- ✅ **Performance**: Lazy loading images
- ✅ **Typography**: Fluid font sizes
